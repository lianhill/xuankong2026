# 🌟 玄空五行择日系统 2026

> 基于玄空风水五行原理，为 2026 年（丙午年）提供吉日查询、穿衣颜色指南的离线 Web 应用。完全适配 iPhone / iPad，支持添加到主屏幕像 App 一样使用。

---

## ✨ 功能特色

| 功能 | 说明 |
|------|------|
| 📅 吉日查询 | 支持 2026 年 3 月～12 月全年吉日速查 |
| 🃏 七日卡片轮播 | 以当天为中心，左右各展示 3 天，滑动切换 |

## 📲 iPhone 使用方法

### 方式一：直接访问网页（推荐）

1. iPhone Safari 打开：**https://lianhill.github.io/xuankong2026/**
2. 点击底部 **分享按钮** `⬆`
3. 选择 **「添加到主屏幕」**
4. 点 **「添加」** — 完成！主屏幕出现「择日2026」图标

### 方式二：离线文件

1. 下载 `index.html` 到本地
2. 通过 AirDrop 传输到 iPhone
3. 在「文件」App 中长按 → 分享 → 在 Safari 中打开
4. 同样可以添加到主屏幕

## 🛠 技术说明

- **纯静态单文件** `index.html`，无任何后端依赖
- **完全离线**：字体使用系统字体（iOS PingFang SC），无 CDN 依赖
- **iOS Safari 兼容**：
  - `font-size: 16px` 防止 Safari 自动缩放
  - `setInterval` 轮询机制解决 iOS 不触发 `change` 事件的问题
  - `safe-area-inset-bottom` 适配 iPhone 底部安全区
  - `apple-mobile-web-app-capable` 全屏 App 模式
- **文件大小**：约 236 KB，加载极快

## 📖 使用说明

1. 打开页面后，在顶部表单选择 **查询日期**
2. 可选填写 **用神** 和 **忌神**（根据个人命盘填写，可留空）
3. 点击 **「🔍 开始查询」**
4. 中央卡片显示当日完整信息，左右滑动查看前后 3 天
5. 中心卡片底部的「**👗 穿衣颜色**」区块显示当日穿衣建议
