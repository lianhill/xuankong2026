# 🌟 玄空五行择日系统 2026

> 基于玄空风水五行原理，为 2026 年（丙午年）提供吉日查询、穿衣颜色指南、AI 解读的离线 Web 应用。完美适配 iPhone / iPad，支持添加到主屏幕像 App 一样使用。

---

## ✨ 功能特色

| 功能 | 说明 |
|------|------|
| 📅 月历网格 | 完整月视图，左右箭头切换月份，支持滑动导航 |
| 🎯 吉日查询 | 2026 年 3 月～12 月全年吉日速查，点击日期查看详情 |
| 🌊 五行分析 | 每日飞星五行、六十甲子、卦象、十二时辰吉凶 |
| 👗 穿衣指南 | 根据当日五行推荐色系 + 回避色系 + 穿搭建议 |
| 🤖 AI 解读 | 接入 DeepSeek API，自然语言每日运势解读（需配置 Key） |
| ⚙️ 开发者模式 | 全可视化 CSS 变量编辑器，实时预览主题更改 |
| 📱 离线可用 | 零外部依赖，无需网络，添加到主屏幕像原生 App |
| 🎨 暖橙琥珀主题 | 深棕背景 + 金橙色调，八卦暗纹水印，沉稳大气 |

## 📲 iPhone 使用方法

### 方式一：直接访问网页（推荐）

1. iPhone Safari 打开：**https://lianhill.github.io/xuankong2026/**
2. 点击底部 **分享按钮** `⬆`
3. 选择 **「添加到主屏幕」**
4. 点 **「添加」** — 主屏幕出现「择日2026」图标

### 方式二：离线文件

1. 下载 `index.html` 到本地
2. AirDrop 到 iPhone → 文件 App → 长按分享 → Safari 打开
3. 同样可添加到主屏幕

---

## 🤖 AI 解读配置

1. 点击右下角 **⚙️ 齿轮图标** 进入开发者模式
2. 在「DeepSeek API」区填入 API Key（从 [platform.deepseek.com](https://platform.deepseek.com/api_keys) 获取）
3. 保存后，在日期详情弹窗中点击「🤖 AI 解读」即可

## ⚙️ 主题自定义

开发者模式支持可视化编辑所有 CSS 颜色变量：

- **背景色**：主/次/三级背景、卡片背景、玻璃面板
- **文字色**：主/次/弱/暗文字
- **品牌色**：主色、强调色、金色
- **五行色**：金💎/木🌿/水🌊/火🔥/土🏔
- **吉凶色**：吉绿/凶红/中性灰

修改实时预览，「保存主题」持久化，「重置默认」一键恢复。

## 🛠 技术说明

- **纯静态单文件** — 零后端依赖，`index.html` 即全部
- **完全离线** — 系统字体（PingFang SC），无 CDN/外部资源
- **iOS Safari 深度兼容**：
  - `font-size: 16px` 防缩放、`setInterval` 轮询 date input
  - `safe-area-inset-bottom` 底部安全区适配
  - `apple-mobile-web-app-capable` 全屏沉浸模式
- **文件大小**：约 119 KB
